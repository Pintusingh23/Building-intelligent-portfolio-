## 📦 Getting Started

### 1. Install dependencies:
```bash
cd frontend
npm install
```

### 2. Run local development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### 3. Production Build:
```bash
npm run build
```
